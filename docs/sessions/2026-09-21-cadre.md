# Corridor cadre — eight agents, one night

*Written for: Rich, and for each agent he spawns. Each agent reads the "Common rules" and its own
section only. Main (the session that wrote this) integrates, runs the bakes, and owns the checklist.*

## How to spawn one (Rich)

```bash
cd /workspaces/apex-conduit
git worktree add ../apex-<agent> -b agent/<agent> main
cd ../apex-<agent> && npm install                      # worktrees share packages/engine — without this @apex/engine resolves to the main checkout
ln -s /workspaces/apex-conduit/tools/corridor/data tools/corridor/data   # the baked sites live once, in the main checkout
mkdir -p /tmp/corridor-mail/<agent>/{inbox,outbox}
```

Then start a Claude Code session in `../apex-<agent>` with this prompt:

> You are the **<agent>** agent of the corridor cadre. Read `docs/sessions/2026-09-21-cadre.md`:
> the "Common rules" section and your own section, nothing else. Then start.

Main watches every `/tmp/corridor-mail/*/outbox`. Agents watch their own `inbox`.

**Rate limit:** main's own sub-agent spawns hit the account's session limit at ~02:40 UTC (resets
03:30 UTC). Separate sessions per worktree are the plan regardless — they also give each agent its own
Vite server and HMR, which is what today's three-agents-in-one-tree pain was about.

## Common rules (every agent)

- **Your worktree, your branch, your dev server.** Run `npx vite --port <your port> apps/corridor`
  (ports in your section). Never touch `/workspaces/apex-conduit` directly. Never restart another
  server, the devproxy on :5190, or cloudflared.
- **Repro first, root cause, fix by design, re-run the repro.** Rich's rule after four rounds of
  guess-and-patch on a bug that was a horizon mesh. For any visual or behaviour claim you make, there
  is a headless probe under `probes/` that shows it (Playwright + swiftshader; copy the boilerplate
  from `probes/corridor-grassperf.mjs`, including the line that blocks `/@vite/client` so a reload
  cannot empty `window.corridor` mid-probe).
- **Measure, don't type.** Numbers come from data or a probe, not from a screenshot. Knobs go in
  `apps/corridor/src/tuning.ts` as `export let` with a `tune()` entry so Rich can drive and paste
  JSON back; he pastes, you set the default.
- **Ownership is by file.** Your section lists what you own. Shared files (`scene.ts`, `main.ts`,
  `tuning.ts`, `index.html`, `style.css`, `editor/main.ts`, `catalog.json`) are additive-only: add a
  section, a knob, a case — never restructure, never revert a line you did not write. If you need a
  shared-file change bigger than that, mail main first.
- **Mail.** Plain markdown files, numbered, `subject:` on the first line, into
  `/tmp/corridor-mail/<you>/outbox/`. Main answers into your `inbox/`. Mail when you start, when you
  need a decision or a shared-file change, when you hand off. Handoff mail lists: what shipped, the
  probe that proves it, knobs added, what you left undone.
- **Green before handoff:** `npx tsc -b apps/corridor` and `npx oxlint apps/corridor`. Commit on
  your branch with clear messages; main merges. Do not push, do not touch `main`.
- **Conventions that bit people today:** three.js `rotation.y = θ` sends local +Z to
  `(sin θ, 0, cos θ)`; a placement's `yaw_deg` is a compass bearing rendered as `-(yaw·π/180)`; the
  bake's `rect.yaw_deg` is a math angle from east (`yaw = -rect.yaw_deg`); tsconfig has
  `erasableSyntaxOnly` (no constructor parameter properties); custom ShaderMaterials need the
  `common` + `logdepthbuf_*` chunks or they vanish; instanced ez-tree leaves need a plain material.
- **Site coordinates:** scene x = site x, scene z = −site y; `groundAt(x, y)` takes site y,
  `heightAt`/`edgeDistance` on `Site` take scene x, z (edgeDistance < 0 = on pavement).

   second, coarser card tier (one card per 4 m²) beats thinning the first.

   says everything looks like April.

5. The strip's mown/rough grass textures become `turf` in this system; the grass agent's blades and

**Done when:** a Bowie fly stance shows forest floor under the trees and turf on the verge with no
visible seam to the pavement; a Sideling cut face reads as rock; frame time within 2 ms of before.
